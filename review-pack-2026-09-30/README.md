Используйте [шаблон эскалации](09-escalation-template.md), чтобы передать наблюдения коллеге. Сначала ответьте самостоятельно, затем прочитайте разбор. SQL использует временные наборы `VALUES` и только `SELECT`: таблицы базы не создаются и не меняются.

Критерий повторения: объяснить наблюдение, назвать альтернативную гипотезу и выбрать проверку, которая их различает. Отмечайте упражнение выполненным только после его выполнения, записав настоящую дату и результат в отдельную заметку.
